# Phase 2 lockfile fixtures

`public-deconf.json` is a minimized formatting-preserving copy of the lockfile from the public [digitalinteraction/deconf repository](https://github.com/digitalinteraction/deconf/blob/main/package-lock.json), retrieved 2026-10-23. It retains the root dev dependency and resolved package metadata used by the dev-path invariant test. The remaining fixtures are synthetic and intentionally small.
